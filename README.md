# UNO Control Android 1.3 (native source)

Нативное Android-приложение на Java без WebView, CSS, JS-фреймворков, внешних сервисов и платного ИИ.
Интерфейс: один главный экран («Сводка»), одно действие обновления, дополнительные разделы в меню `⋮`.
Репозиторий по умолчанию: `ivankondral1998-dot/UNO-android-AI-Agent`, можно менять в настройках.

## Сборка APK
Требуется Android SDK 35, JDK 17+, Android Gradle Plugin 8.7.3 и Gradle 8.9.
В корне проекта: `gradle :app:assembleDebug` (при установленном Gradle 8.9), APK находится в
`app/build/outputs/apk/debug/app-debug.apk`. Проверки: `gradle :app:testDebugUnitTest`. Для релиза требуется своя подпись.

## Что реализовано
- Чтение GitHub REST API только GET по HTTPS (не требует платного AI API).
- Публичные проекты работают без токена, приватные требуют PAT с правом read-only Contents+Metadata.
- Токен хранится только в RAM процесса. Не попадает в SharedPreferences, логи или экспорт.
- Сверка веток, последних коммитов, задач и pull requests. Ограничения выборки показываются явно.
- Сравнение с предыдущим успешным снимком, без ложных заявлений о готовности проекта.
- Локальное сохранение данных в приватном хранилище приложения; импорт бэкапа UNO Control v1.2 в отдельный архив.
- Нативный минималистичный интерфейс. Не содержит WebView.

## Ограничения
- Нет оценки качества кода или проверки тестов и Actions; коммиты и PR не доказывают готовность.
- Ветки загружаются порциями по 100, максимум 20 страниц. При превышении число отмечается как неполное.
- Нет фоновой синхронизации. Повторное подключение приватного репозитория после закрытия процесса требует ввода токена.
- Релизная проверка на реальном Android не выполнена; без Android SDK эта среда не собирает APK.

## Безопасность
Приложение не модифицирует GitHub. Для приватного репозитория GitHub требует учётных данных; приложение
не обходит авторизацию. Поставщик приложения не получает токены и данные через отдельный сервер.

## Проверки в среде подготовки
