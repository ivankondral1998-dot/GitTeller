# GitTeller — исправленная исследовательская исходная версия 1.0.1

**Это ИСХОДНИК, НЕ ИСПРАВЛЕННЫЙ APK.** Он отделён от исходных файлов Grok. Авторизованная сборка Android SDK, запуск в эмуляторе и установка на Samsung A52 для этого исходника **не проводились**. Не продавайте и не распространяйте как готовый продукт.

## Что есть в исходниках

- Нативный Android UI на Java без WebView; простой домашний экран, подробности через «Подробнее» и меню ⋮.
- GitHub REST API: HTTPS GET для веток, HEAD SHA, коммитов, Issues и PR. Для публичных репозиториев — без токена, для приватных — токен только на чтение, вводимый самим пользователем.
- Данные сохраняются раздельно для разных репозиториев, доступен офлайн-просмотр; неполные списки не трактуются как удаление веток.
- Токен GitHub не сохраняется приложением. Смена репозитория сбрасывает прежний токен.
- Экспорт JSON через Android Storage Access Framework с отбором полей и импорт с явным подтверждением замены. Импортированные данные помечены как не проверенные в GitHub.
- Осторожные пояснения названий коммитов по правилам. **Это не ИИ-анализ кода и не независимая проверка работоспособности!**

## Требования к сборке (на устройстве разработчика)

- JDK 17+, Android SDK platform 35 и build-tools 35.0.0, Gradle 8.9, Android Gradle Plugin 8.7.3.
- В каталоге проекта: `gradle --no-daemon :app:testDebugUnitTest` и `gradle --no-daemon :app:assembleDebug`.
- Результат, если сборка успешна: `app/build/outputs/apk/debug/app-debug.apk`.
- **У нас в этом чате нет Android SDK/Gradle, поэтому после наших правок эти команды не запускались.** Даже удачная сборка не доказывает работу на телефоне.
- `testImplementation 'org.json:json:20240303'` добавлено только для JVM unit-тестов, чтобы не использовать заглушку `org.json` из android.jar.

## Проверки текущей итерации

- Все 6 Java-файлов успешно **разобраны Java-компилятором (PARSE OK)** — только синтаксис.
- Локально скомпилированы `Summary.java`, `CommitExplainer.java` с тестовыми реализациями `org.json`; **11 проверок логики** прошли.
- Поскольку использовались JSON-заглушки, это **не доказательство выполнения Android/Gradle unit-тестов**.
- В оригинальном пакете Grok 4/4 Gradle unit-тестов — FAILED.

## Ограничения

- Нет проверки на Android A52, эмуляторе, тестов HTTPS GitHub со смартфона, оценки производительности и качества экрана.
- Автоматический анализ произвольного кода, реальная оценка завершённости задачи и функциональной готовности не реализованы.
- Чтение истории коммитов выполняется для ветки по умолчанию; выбор произвольной ветки в UI ещё не реализован.
- Отдельная система локальных заметок и развитый менеджер проектов не реализованы; пока смена репозитория через настройки.
- Система не проверяет GitHub Actions, CI, реальные тесты APK и безопасность кода.
- Экспортированные данные содержат сведения о проекте, возможно приватные: владелец должен сам решать, кому их передавать.
- Используется только русский язык, и часть строк остаётся прямо в Java. Нет иконки и релизной подписи.
- Исходный архив `BASE_ANDROID_SOURCE_v1.3.zip` сохранён для отката.
