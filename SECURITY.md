# SECURITY.md

## Токен и аутентификация
- Для публичных репозиториев токен не требуется.
- Для приватных: fine-grained PAT с правами только чтение (Contents + Metadata).
- Токен хранится **только в оперативной памяти процесса** (поле `token` в MainActivity). Не пишется в SharedPreferences, не логируется, не экспортируется, не попадает в APK.
- При перезапуске приложения токен нужно ввести заново. Keystore не используется в этой версии (допустимо по ТЗ: «либо пока оставить только в памяти процесса»).

## Сеть
- Только HTTPS GET к https://api.github.com/...
- Никаких POST/PATCH/DELETE, никаких изменений на GitHub.
- Обработка ошибок 401/403/404/429 и лимитов: показываются пользователю, старый снимок сохраняется.

## Хранилище
- Снимки (JSON) в приватном SharedPreferences приложения (ключ с префиксом репо).
- Резервная копия: локальный JSON **без токена**, с проверкой схемы при импорте.
- allowBackup="false".

## Разрешения
- Только `android.permission.INTERNET`.
- Нет лишних permissions, нет WebView, нет аналитики, нет телеметрии.

## Прочее
- В коммерческой сборке нет демонстрационных данных приватного UNO.
- Репозиторий по умолчанию — публичный `octocat/Hello-World`.
