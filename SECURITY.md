# Безопасность 1.0.8-dev

- Только HTTPS GET. Токен в заголовке, не в адресе. Сравнение веток и чтение одной записи тоже GET.
- `TokenVault`: Android Keystore, AES-GCM, файл только в `noBackupFilesDir`, `allowBackup=false`.
- Замена файла токена не удаляет рабочую запись до успешного `rename`. Сбой установки возвращает прежний ciphertext. Это проверено на обычных файлах, не на живом Keystore.
- `hasToken` означает, что файл записи есть. Это не доказательство, что Android его расшифрует.
- Пустое поле токена сохранённый секрет не стирает.
- Экспорт и краткий отчёт не содержат токен, `Authorization` и тело записи. Импорт принудительно помечается как не свежая проверка.
- `ghp_` и `github_pat_` в коде — шаблоны маскирования ошибок.
- Java `String` из памяти не стирается.
- PAT владельца в этой сборке не использовался.
