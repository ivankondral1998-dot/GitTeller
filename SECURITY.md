# Безопасность 1.0.5

- Только HTTPS GET. Токен в заголовке Authorization, не в URL.
- `TokenVault`: Android Keystore, AES-GCM, файл в `noBackupFilesDir`. `allowBackup=false`.
- Экспорт JSON не включает токен. Поле ввода не заполняется сохранённым секретом.
- `github_pat_` в коде — шаблон редактирования ошибок, не сохранённый секрет.
- Java `String` из памяти не стирается. Это не защита от root и дампа процесса.
- Приватный PAT в этой сборке не использовался.
