# Исправления ChatGPT — GitTeller 1.0.1 SOURCE

Изменения внесены **в отдельную копию исходного проекта**, не в GitHub, не в APK Grok и не в исходный архив UNO.

1. `MainActivity.java`: компактный главный экран, подробный отчёт отдельно, информация об устаревании среза (>6 ч), отдельная отметка об импорте из файла.
2. `MainActivity.java`: сброс токена при смене репозитория; сброс `loading` при завершении старой синхронизации после смены проекта, защита обработчиков от уничтоженной Activity.
3. `MainActivity.java`: безопасный экспорт JSON через SAF (без переменной PAT), восстановление родного JSON с проверкой схемы, предупреждением и подтверждением; список сохраняемых полей явно ограничен.
4. `MainActivity.java`: подробный отчёт о SHA-сдвигах и изменениях статусов уже существующих Issues/PR из доступной выборки; не утверждает удаление при неполных списках.
5. `Summary.java`: при неполной выборке вместо «Новых изменений не обнаружено» говорит «Сравнение неполное»; совпавшие SHA не трактуются как отсутствие любых изменений.
6. `CommitExplainer.java` (новый): осторожные объяснения из заголовка коммита (`fix`, `feat`, `docs`, `test`), включая прямое предупреждение об отсутствии проверки; **не претендует на понимание кода**.
7. `build.gradle`: добавлена `org.json:json:20240303` для настоящих JVM unit-тестов, которые в исходнике падали из-за Android mockable json; новая версия тестов ещё НЕ запускалась с Gradle.
8. `AndroidManifest`, `styles.xml`, `settings.gradle`, `GithubClient.java`: обновлён брендинг; applicationId `app.gitteller.mobile` (новый пакет, не обновляет прежний `app.unocontrol`).
9. Добавлены unit-тесты CommitExplainer + 2 теста Summary; сохранены старые тесты.
