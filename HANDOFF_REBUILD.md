# Следующая техническая задача для исполнителя с Android SDK

Это продолжение GitTeller, не новый проект. Используйте исходники этой папки, оригинальный пакет Grok оставьте для отката.

1. Установить/подтвердить SDK 35, build-tools 35.0.0, Gradle 8.9, JDK 17+; выполнить `gradle --no-daemon :app:testDebugUnitTest`, предоставить полный лог, exit code и результаты по каждому тесту. JSON-зависимость появилась только для JVM unit-тестов; при проблемах разрешать их, а не отключать проверки.
2. Собрать реальный новый APK `gradle --no-daemon :app:assembleDebug`; передать SHA-256 и appId/version из APK (не из README). Проверить отсутствие debug-секретов и лишних permissions.
3. На Android 14 проверить запуск, узкий экран, смену проектов в момент синхронизации, два публичных репозитория, приватный тестовый репозиторий только с разрешённым тестовым PAT, поведение 401/403/404/429, offline, сохранение, экспорт/импорт, импортированное не выдавать за проверенное.
4. Исправить выявленные проблемы и добавить тесты для HTTP и JSON-import (не менее 12 сценариев P0 из исходного задания). Без доказательств не писать PASS или RELEASE_READY.
5. Добавить наглядные скриншоты **фактически запущенного приложения**, не макеты. Иконку, безопасное хранение приватных данных, структурированные строковые ресурсы и UI улучшать после блокирующих проблем.
6. Финальная передача — APK + полные исходники + логи + список невыполненного. Не менять GitHub/UNO и не запускать Actions.
