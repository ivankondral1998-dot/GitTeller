## Реальный дефект P1: ложное появление новых веток

`Summary.of()` версии 1.0.2 увеличивал `added`, если ветка была в текущем снимке, но отсутствовала в ПРЕДЫДУЩЕМ НЕПОЛНОМ. Отсутствие записи в неполном списке не подтверждает новую ветку. Исправлено: такие записи помечаются только как «впервые встретились в выборке», а `added` не увеличивается. Добавлен регрессионный тест.

## Реальный дефект P1: импорт под видом доказательства

`Summary.of()` версии 1.0.2 сравнивал пользовательские данные `restoredFromBackup=true` с другими данными как будто они являются проверенной историей GitHub. Исправлено: импортированная запись явно обозначена, сравнение нового сетевого снимка с неподтверждённой импортированной базой не производится. Добавлены регрессионные тесты.

## Исправлен P2: неполная первая сверка

В первом снимке неполный список и предупреждения не отражались в главном резюме. Теперь указано, если список неполный или есть предупреждения API.

## ВАЖНОЕ ИСПРАВЛЕНИЕ ПРЕЖНЕГО ВЫВОДА АУДИТОРА

Первоначальная гипотеза о том, что метод `slimIssues` удаляет PR из `/pulls`, НЕ ПОДТВЕРДИЛАСЬ. API `/issues` может включать PR с ключом `pull_request` и именно поэтому их нужно исключать из Issues. Отдельный `/pulls` возвращает записи PR. Код вызывает один и тот же фильтр, но для обычного ответа `/pulls` этот ключ не присутствует. Не записывать это как доказанный дефект.

## Не проверено / обязательный следующий шаг

1. **Нового APK 1.0.3-audit нет:** отсутствуют Android SDK / Gradle в среде этого аудита. Для сборки нужен соответствующий SDK и Gradle.
2. Физический A52 не использовался. Эмулятор не показал успешный запуск главного экрана. Статус `NOT_DEVICE_VERIFIED`.
3. Приватный GitHub с PAT, обмен JSON через SAF, обработка Android жизненного цикла, системные темы и сетевые таймауты не были протестированы на устройстве.
4. В приложении нет полноценного анализа исходного кода, проверки корректности функций или автоматического доказательства PASS. Сейчас это обзор GitHub-снимков и осторожные пояснения по заголовкам коммитов.
5. Ранее заявленную команду Gradle `:app:testDebugUnitTest` необходимо повторить в чистой среде и сохранить исходный лог без подмены результата прямым JUnit.

Статус: исходный APK 1.0.2 существует, приёмка 1.0.2 не пройдена; 1.0.3-audit содержит проверяемые исправления исходников, но НЕ является Android-сборкой.
