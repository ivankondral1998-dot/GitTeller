# Что не доказано в 1.0.8-dev

1. Физический Samsung A52: **NOT_DEVICE_VERIFIED**. Обновление поверх 1.0.7, Keystore, перезапуск и `force-stop` на телефоне не выполнялись.
2. Эмулятор Android 14: **NOT_RUN**. Процесс дошёл до конца загрузки и умер на `ColorBuffer` до установки APK. Кадров экранов нет.
3. Приватный репозиторий и реальный fine-grained PAT: **NOT_RUN**. Токен владельца в отчёт не попадал.
4. Живой Android Keystore: запись, сбой `rename` внутри Keystore, повреждённый контейнер и два токена на два проекта — **NOT_RUN** на устройстве. Отказ установки проверен только как замена обычных файлов (`EventModelTest.failedTokenInstallKeepsPreviousCiphertext`).
5. Гонка «сменить проект, пока идёт запрос» на живом UI не снималась. В коде стоят `syncEpoch`, `compareEpoch` и отмена сокета.
6. Gradle Test Executor в этой среде несколько раз падает на постороннем соединении (`Unexpected type tag 71`). Успешным считается только прогон с `BUILD SUCCESSFUL` и свежим XML. Падения не скрыты.
7. Списки задач и предложений обрезаются двумя страницами по 100, ветки — пятью. Это неполный архив GitHub и так и подписано.
8. ETag берётся только у первой страницы и только если прошлый список короче 100 и был полным. Изменение на второй странице при неизменной первой эта схема не увидит, поэтому длинные списки по ETag не подменяются.
9. Фильтр «Проверки» в ленте пуст, пока нет отдельного сохранённого события проверки. Checks по-прежнему читаются при открытии записи и не объявляются успехом, если их нет.
10. Сравнение GitHub на живом репозитории в этой сдаче не гонялось как обязательный сетевой тест. Тексты `ahead` / `behind` / `diverged` / `identical` / 404 / 409 проверены без сети. Большой ответ compare на практике не снимался.
11. Коммерческая готовность, OAuth и публикация в Play не заявляются.
