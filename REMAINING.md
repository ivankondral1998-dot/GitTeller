# REMAINING — после 1.0.4-dev

Ближайший недоказанный критерий: живой кадр главного экрана GitTeller и `pm clear` без падения, когда Keystore-ключ исчез. Эмулятор Android 14 это не довёл: хост убил qemu по OOM после того, как инструментальные тесты хранилища уже прошли.

Дальше, без выдуманного PASS:

- Установка на физический Samsung A52. Пока NOT_DEVICE_VERIFIED.
- Чтение приватного репозитория fine-grained PAT только на чтение (Metadata, Contents, при необходимости Issues и Pull requests). Токен в чат не присылать. Сейчас NOT_RUN.
- Поворот экрана и смена репозитория во время незавершённого HTTP — в коде есть сброс `syncEpoch` и `HttpURLConnection.disconnect()`. На устройстве не прогонялось.
- Внешний `run-as`/`grep` ciphertext. Внутренний assert теста прошёл, отдельная команда adb — нет.
- Java не позволяет обнулить `String`. Временный ввод живёт, пока его не соберёт GC. Root и отладчик процесса это читают. В тексте приложения это не названо неуязвимостью.
- Debug-сборка, без подписи релиза, без иконки, без ProGuard.
- Gradle Test Executor в этой среде нестабилен: один прогон FAIL (`Connection refused`), следующий PASS с XML. Повторять на машине владельца.
- Лимит GitHub и чужие репозитории в этот заход по сети не гонялись, чтобы не жечь квоту после прошлых публичных чтений.
