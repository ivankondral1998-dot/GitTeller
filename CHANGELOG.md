# Changelog

## 1.0.8-dev (versionCode 23)

- Новая задача, смена названия, правка `updated_at` и слияние PR считаются изменениями, даже если SHA веток и поле `state` не сдвинулись. Закрытие по-прежнему не называется слиянием и не называется готовностью.
- Исчезновение номера из неполного списка не называется удалением. Если номера нет в обоих полных списках, лента говорит только, что его нет в новой выборке.
- Для открытого направления с другим указателем запрашивается `GET /compare/{old}...{new}`: впереди, откат, расхождение, совпадение или «Недостаточно данных». Откат не называется прогрессом. Ошибка сравнения не стирает снимок.
- Лента до 30 событий на проект: событие, основание, что не подтверждено, ссылка `https://github.com/` этого репозитория. Фильтры: все, новое, проверки, задачи, слияния. Проверок в ленте нет, пока GitHub их не отдал отдельным фактом.
- Первая страница полного короткого списка веток, задач и предложений может уйти с `If-None-Match`. Ответ 304 не называется новой полной историей. Списки длиннее одной страницы по ETag не кэшируются: страница 2 может измениться при той же первой странице.
- Замена токена пишет временный файл и ставит его на место через запасную копию. Если установка не удалась, читается прежняя запись. Наличие файла не называется успешной расшифровкой.
- Импорт помечается `IMPORTED` и не становится базой для «живого» прогресса. В архиве сохраняются `merged`, `merged_at` и `updated_at`. Секреты и неизвестные поля по-прежнему выбрасываются.
- Главный экран остаётся коротким: не больше двух фраз о событии, без SHA. Частичный срез не называется полной проверкой.

## 1.0.7-dev (versionCode 22)

- Сравниваются указатели всех загруженных веток, а не только последний коммит `main`. Сдвиг `research/*` при неподвижном `main` описывается отдельно. Первая проверка не называется сравнением.
- Неполный список веток, задач или предложений не выдаётся за полную картину. Если раздел не обновился, остаётся прошлый список и ставится пометка, что он не свежий.
- Ошибки GitHub разделены: 401, 404, 403 без прав, 403/429 с лимитом. Лимит не повторяется сразу. Тайм-аут показывается по-русски. Старый снимок при полном сбое не затирается. Токен при ошибке сети не удаляется.
- Проверки: сначала check-runs, затем статусы коммита, затем GitHub Actions для того же SHA. Пустой ответ, `skipped` и `neutral` не называются успехом.
- Главный экран: что изменилось, что требует внимания, следующий шаг, кнопка «Обновить», дата последней удачной загрузки и покрытие. SHA и сырой HTTP с главного экрана убраны.
- Отдельные экраны: обзор, направления, история, задачи, предложения, надёжность, подключение, настройки. У записи: что произошло, что известно, чего нельзя установить, источник и технические детали с копированием.
- Закрытый запрос изменений не называется внесённым без отметки GitHub. `[skip ci]` не считается проверкой. Префикс ветки — предположение по названию.

## 1.0.6 (versionCode 21)

- Пустой или оборванный список задач и предложений больше не выглядит как «ноль записей».
- Смена статуса задачи при тех же SHA веток видна на главном экране и не называется готовностью.
- Старый снимок без признака полноты не сравнивается как полный.
- Неполный список не подписывается фразой «новых сдвигов нет».
- Экран задачи, предложения и коммита запрашивает одну запись GitHub: текст, файлы, check-runs. Нет ответа — «Недостаточно данных».

## 1.0.5 (versionCode 20)

- Один статус и одна кнопка на главном. Списки не в диалоге со SHA.
