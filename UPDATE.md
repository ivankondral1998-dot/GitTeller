# Обновление до 1.0.8-dev без потери доступа

`applicationId` не менялся: `app.gitteller.mobile`.  
Сертификат этого debug-APK совпадает с 1.0.7 и 1.0.6:

`SHA-256` `67ec79901c9ff9f59d9dc1387efd7b759cfd716953bd2d0385076e68bd26b6ef`

Поверх можно ставить только сборку с тем же ключом. Другой ключ Android отклонит. Удаление приложения сотрёт Keystore.

Как ставить, если ключ тот же:

1. Не удаляйте приложение и не очищайте его данные. Не делайте `pm clear`.
2. Установите `GitTeller-1.0.8-dev.apk` поверх (adb `install -r` или установщик Android). `versionCode` 23 выше 22.
3. Токены лежат в Android Keystore и в `noBackupFilesDir` (`token-vault-v1`). Обычное обновление их не удаляет.
4. Снимки проекта лежат в `SharedPreferences` `gitteller_v1`. Они сохраняются. Лента событий — отдельный ключ `{repo}:feed`, тоже на устройстве, без токена.
5. Пустое поле токена на экране «Подключение GitHub» сохранённый токен не стирает. Удаление токена спрашивает подтверждение и касается только выбранного проекта.
6. Резервный JSON по-прежнему без токена. После импорта источник — `IMPORTED`, не свежая проверка GitHub. Старая лента этого проекта при импорте очищается, чтобы импорт не выглядел живыми событиями.

Если установка пишет, что подпись не совпадает, остановитесь. Не удаляйте приложение ради новой сборки, пока не решите, что токен можно ввести заново.

Эта сборка не проверена на Samsung A52. Успешная компиляция не означает, что телефон уже принял обновление.
