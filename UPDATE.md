# Обновление до 1.0.7-dev без потери доступа

`applicationId` не менялся: `app.gitteller.mobile`.  
Сертификат этого debug-APK совпадает с сертификатом приложенного APK 1.0.6. Поверх можно ставить только сборку с тем же ключом. Другой ключ Android отклонит как конфликт подписи: тогда ставить поверх нельзя, удаление сотрёт Keystore.

Как ставить, если ключ тот же:

1. Не удаляйте приложение и не очищайте его данные.
2. Установите `GitTeller-1.0.7-dev-debug.apk` поверх (adb `install -r` или установщик Android).
3. Токены лежат в Android Keystore и в `noBackupFilesDir` (`token-vault-v1`). Обычное обновление их не удаляет. Очистка данных и удаление приложения удаляют.
4. Снимки проекта лежат в `SharedPreferences` `gitteller_v1`. Они тоже сохраняются при обновлении поверх.
5. Пустое поле токена на экране «Подключение GitHub» сохранённый токен не стирает. Удаление токена спрашивает подтверждение и касается только выбранного проекта.
6. Резервный JSON по-прежнему без токена. Его нельзя считать свежей проверкой GitHub.

Если установка пишет, что подпись не совпадает, остановитесь. Не удаляйте приложение ради новой сборки, пока не решите, что токен можно ввести заново.
